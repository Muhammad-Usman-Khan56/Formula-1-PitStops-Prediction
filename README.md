# Formula-1-PitStops-Prediction
End-to-end machine learning project for Formula 1 pit stop prediction using feature engineering, EDA, and LightGBM.

## Features

- Exploratory Data Analysis (EDA)
- Feature Engineering
- GroupKFold Cross Validation
- LightGBM Modeling
- Feature Importance Analysis

## Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- LightGBM
- Matplotlib
- Seaborn

## Future Improvements

- Hyperparameter tuning
- XGBoost/CatBoost models
- Ensembled models
- Real-time prediction pipeline
- Streamlit dashboard
